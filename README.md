# Flight Weather Briefing
Weather form for flight training (METAR/TAF). Sources: NOAA Aviation Weather Center (official), Open-Meteo (model values, clearly marked). No API keys needed. NOTAMs are a link to the official FAA site.
Run locally: `npm install && npm start` then open http://localhost:3000
Deploy on Render: New > Web Service > this repo. Build `npm install`, Start `npm start`, Instance Free.
For training and situational awareness only. Not an official briefing.
